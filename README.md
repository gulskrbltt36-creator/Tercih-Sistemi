# UniTercihGUI - University Preference System

This project is a desktop-based simulation and analysis application developed using C++ and the Qt framework, designed to facilitate and optimize the university preference process for prospective students. The system ensures high-performance search and sorting operations by utilizing advanced data structures such as Hash Tables, Tries, Dynamic Arrays, and Max-Heaps.

## Key Features

* User-friendly interface with registration and system login capabilities[cite: 1].
* Advanced search functionality to easily find and add universities or departments to the preference list[cite: 1].
* Ability to modify the preference list order (move items up/down), remove selections, and undo recent actions[cite: 1].
* Dynamic analysis system that calculates and displays the probability of placement (e.g., Safe, Likely, Risky) based on the student's ranking[cite: 1].
* Detailed comparison tool to evaluate two selected departments, providing insights on rankings, quotas, and AI-supported analysis of city life and dormitory options[cite: 1].
* Integrated AI Assistant to guide user interactions and support preference analysis[cite: 1].
* Capability to export the finalized preference list as a text document (.txt) report to the local machine[cite: 1].
* One-click action to completely clear the active preference list[cite: 1].

## Technologies Used

* **Programming Language:** C++
* **User Interface (GUI):** Qt Framework
* **Core Architecture:** Advanced Data Structures (Trie, Hash Tables, Max-Heaps)
